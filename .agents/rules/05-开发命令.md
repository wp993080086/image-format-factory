# 开发

```bash
flutter pub get
flutter analyze
flutter test
flutter run -d windows
```

注意：本机代理环境会导致 `flutter test` 无法连接 flutter_tester，
运行测试前临时清空代理变量：`http_proxy= https_proxy= HTTP_PROXY= HTTPS_PROXY= flutter test`

Android arm64 Release 包（当前真机测试用）：

```bash
http_proxy= https_proxy= HTTP_PROXY= HTTPS_PROXY= \
  flutter build apk --release --split-per-abi --target-platform android-arm64
```

- 必须带 `--split-per-abi`：不带时产出的 `app-release.apk` 会混入旧 ABI 残留的 JNI 库；
- 产物 `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk` 复制到 `dist/android/`，更新 `SHA256SUMS.txt`；
- 发布前用 `apksigner verify --print-certs` 校验签名，并确认包内 `lib/` 只有 `arm64-v8a`。
