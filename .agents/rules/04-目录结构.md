# 目录结构

```
lib/
├── app/                  # 应用入口：MaterialApp、路由、主题、快捷键
├── core/
│   ├── batch/            # 批量队列模型（BatchItem / BatchConfig）与执行器
│   ├── di/               # Riverpod providers
│   ├── error/            # 错误码体系与导出错误映射
│   ├── image/            # 纯 Dart 图像处理：编解码/裁剪/缩放/调色/模糊/水印/标注/格式探测
│   │                     # （font/ 子目录为生成的点阵字库数据）
│   ├── log/              # AppLogger 与日志留存
│   └── platform/         # 端检测 + 各端能力矩阵（PRD 七章）
├── features/             # 功能模块：home / crop / resize / export / annotate / batch / editor / about
│                         # - 格式转换与压缩合并为 export 单页，靠 ?tab= 区分分区
│                         # - annotate 页同时承载涂抹打码、马赛克与整图模糊
│                         # - editor 存放编辑会话 controller / state（annotate 页共用）
├── services/
│   ├── batch/            # 批量流水线：编排 core 各步骤，单图 = N=1 特例
│   ├── file/             # 导入导出服务（file_selector 薄层 + 平台条件导入）
│   └── image/            # 原生编解码适配：AVIF / HEIF / WebP
│                         # （每种格式各有 *_native.dart / *_ffi.dart / *_stub.dart 分层）
└── main.dart
```

职责边界：
- `core/` 只放与 UI 无关的纯逻辑；`features/` 只放页面与页面级 controller；
- 跨多个 core 模块的流程编排放 `services/`，不在 features 页面里直接串步骤；
- 平台差异在 `core/platform` 能力矩阵判定，`services/*_stub.dart` 只做不可用降级。
