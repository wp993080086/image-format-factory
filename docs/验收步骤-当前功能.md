# 像素工坊 · 当前功能验收步骤

> 版本：v1.0（2026-11-13）
> 范围：**仓库当前 HEAD 已实现且可运行的功能**（不含鸿蒙、不含 Web 运行时）。
> 用法：从第 2 节自动化门禁开始，再按 V 系列逐条点，每条都有可判定的预期。❌ 记下错误码与截图。

## 1. 已实现功能清单

| 模块 | 已实现 | 端 | 覆盖方式 |
|------|--------|----|----------|

| 导入 | HEIC / HEIF（苹果 HEIC、华为 HEIF）：Android 走系统解码，Windows 走随包 libheif | Windows / Android | 手工 + 单测 + **需真机**（Android） |

| 导入 | 拖拽导入（单个取第一张，非图片直接提示） | Windows | 手工 |
| 裁剪 | 矩形 / 圆形选区，自由 / 1:1 / 4:3 / 3:2 / 16:9 | Windows | 手工 + 单测 |
| 裁剪 | 宽高像素输入、还原整图、方向键平移（Shift 步长 10）、Ctrl+0 | Windows | 手工 + 单测 |
| 尺寸 | 拉伸填充 / 裁剪填充 / 留白填充，锁定原图比例 | Windows | 手工 + 单测 |
| 尺寸 | 单边放大 4 倍上限、总像素 4000 万上限、放大画质提示 | 同上 | 单测 |
| 导出 | JPEG（质量可调）/ PNG（压缩级别可调）/ BMP / ICO（16~256 多尺寸） | Windows / Android | 手工 + 单测 |
| 导出 | WebP（质量可调）：Windows 走随包 libwebp，Android 走系统编码器 | Windows / Android | 手工 + 单测 + **需真机**（Android） |
| 导出 | 体积预估（300ms 防抖）、完成态双出口（继续编辑 / 完成） | 同上 | 手工 |
| 导出 | Android 走 SAF 系统保存面板（`ACTION_CREATE_DOCUMENT`） | Android | 单测 + **需真机** |
| 错误 | `E-IMG-001~005`、`E-EXPORT-001~006` 全部可触发并分级 | Windows / Android | 单测 + 手工 |
| 其它 | 关于页（版本、隐私说明、诊断日志导出）、明暗主题、无障碍标签 | Windows / Android | 手工 + 单测 |
| 其它 | 移动端 1.3× 字号不破版、WCAG 对比度 | 两端 | 单测 |

### V2 导入分支

样本准备（PowerShell，一次性；文件名用英文，避免控制台编码踩坑）：

```powershell
$dir = "$env:TEMP\pf-samples"; New-Item -ItemType Directory -Force $dir | Out-Null
Add-Type -AssemblyName System.Drawing
# 1) 透明背景 PNG（alpha 只有 0 / 255）
$b = New-Object System.Drawing.Bitmap(800,600)
$g = [System.Drawing.Graphics]::FromImage($b); $g.Clear([System.Drawing.Color]::Transparent)
$g.FillEllipse([System.Drawing.Brushes]::Orange, 100,100,400,400); $g.Dispose()
$b.Save("$dir\transparent.png",[System.Drawing.Imaging.ImageFormat]::Png); $b.Dispose()
# 2) 半透明 PNG（alpha=128，用于验证 PNG8 被禁用）
$b = New-Object System.Drawing.Bitmap(600,400)
$g = [System.Drawing.Graphics]::FromImage($b); $g.Clear([System.Drawing.Color]::White)
$br = New-Object System.Drawing.SolidBrush([System.Drawing.Color]::FromArgb(128,255,0,0))
$g.FillEllipse($br,50,50,400,300)
$br.Dispose(); $g.Dispose()
$b.Save("$dir\semi.png",[System.Drawing.Imaging.ImageFormat]::Png); $b.Dispose()
# 3) 超大图 12000×9000 = 108 MP（超桌面 100MP 上限，约 324MB 内存）
$b = New-Object System.Drawing.Bitmap(12000,9000)
$g = [System.Drawing.Graphics]::FromImage($b); $g.Clear([System.Drawing.Color]::LightSteelBlue); $g.Dispose()
$b.Save("$dir\big.png",[System.Drawing.Imaging.ImageFormat]::Png); $b.Dispose()
# 4) 伪装成 PNG 的纯文本
"not an image" | Set-Content "$dir\fake.png"
```

安装方式（二选一）：

```bash
# 方式一：USB 连接后 adb 安装
adb install -r dist/android/pixel-forge-0.1.0-arm64-v8a-release.apk

# 方式二：把 APK 传到手机，用文件管理器点击安装
# 需要在系统设置里允许「安装未知来源应用」
```

包名 `com.pixelforge.pixel_forge`，应用名「像素工坊」。用 debug key 签名，仅供自测，不能上架；如已装过 debug 版需先卸载（签名不一致会覆盖失败）。
